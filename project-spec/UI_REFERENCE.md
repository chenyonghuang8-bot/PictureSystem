## 设计语言

关键词：
- family
- warm
- calm
- premium
- photo-first
- minimal

### 色彩
- 暖白 / 米白背景
- 深灰文字
- 低对比辅助文字
- 绿色作为主要交互强调色
- 避免大面积饱和色

### 形状
- 大圆角
- 轻边框
- 极弱阴影
- pill filter
- avatar group

### 图片
图片是界面主角。
不要让统计卡片、图标或文字抢过图片视觉层级。

---

# App

底部固定四栏：
1. 照片
2. 相册
3. 回忆
4. 我的

首页“照片”：
- 家庭标题
- member avatars
- 搜索框
- 往年今日
- 相册快捷入口
- 月份标题
- 照片 grid
- 浮动上传按钮

第一屏应该让用户立刻看到照片。

---

# Web

布局：
- 左侧主导航
- 中央照片内容
- 右侧辅助信息

左栏：
- family title
- 照片
- 相册
- 回忆
- 地图
- 收藏
- 家庭成员
- 管理后台（仅管理员）

中央：
- search
- memories
- album shortcuts
- timeline grid

右侧：
- storage usage
- recent uploads
- family featured
- small stats

注意：
右侧不是传统 BI dashboard。
只能作为辅助信息。

---

# Admin

即使进入管理后台，也保持同一视觉系统。
可以信息密度更高，但不要突然变成蓝灰色企业 SaaS dashboard。

---

# Responsive

Web：
- Desktop: 三栏
- Tablet: 左栏可折叠，右栏下沉或隐藏
- Mobile web: 单栏，接近 App 信息结构

---

# Accessibility

- 正文文字对比度合格
- 点击区域至少舒适
- 不仅用颜色表达状态
- 图片提供可选 alt/description
- keyboard focus 清晰
